HamNavigator MY SHACK 1.9.22

In-flight Cloud work can exceed 45 seconds. A verified stopping backend gets
up to five minutes to finish saving. Wait in setup. No process is killed.
New sync and delivery passes do not start after shutdown is requested.

A backend already saving and stopping is allowed to finish without another
stop command. Concurrent shutdown HTTP 503 is checked against that backend.
Setup still waits for process exit and blocks on save failure or timeout.

Use the built-in Update button. The new installer closes older running versions
through their existing local connection, without restarting their graphical stack.
No separate manual installation is needed. Finish open save dialogs in Digital/Map;
files are replaced only after normal shutdown. Cancel an old failed installer and
reopen Update to fetch the latest release. Errors include the failed step and code.

Choose Språk / Language in MY SHACK to select Norwegian, English or Swedish.
MY SHACK changes immediately. Restart HamNavigator for the Windows panels,
Digital and Map to use the new language. Stop transmission before restarting.
The language is saved on this PC. Contacts, passwords and radio settings
are retained. Shared radio messages and contact data are not translated.

The user guides for MY SHACK, Digital and Map are available in all three languages
inside the programs, including offline search where supported.

Sign in with your HamNavigator account. Use the same account on your PCs
and mobile device for Cloud synchronisation. Configure audio, USB and CAT/PTT
on each device. Updating does not resume radio transmission.

source code are included with the public client release. Server files remain private.
