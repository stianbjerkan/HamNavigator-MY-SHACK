Field setup with DE-19 or Digirig

Connect the interface to a Pi 4 USB-A port using a data cable. Start with one interface connected. On a Xiegu G90, connect both audio and CAT between radio and interface. Use the cables and Digirig variant for your radio.

Sign in under Account and Cloud. Open HamNavigator Digital from the digital page. In sound settings select the interface for both USB input and output. In interface settings select the radio, its configured baud rate and serial port. Prefer serial/by-id, or use serial/by-path for a fixed USB socket. Connect the adapter before opening Digital.

Set PTT for the DE-19 according to your radio and cable configuration. Digirig Mobile can use RTS on the CAT port with an RTS-wired PTT cable. Verify the waterfall, decoding and CAT frequency readback before a transmission. Check UTC time before field FT8.

The shared log is hamnavigator.adi in ~/.local/share/hamnavigator-portable/log by default. Choose manual or automatic synchronization in Account and Cloud. USB and sound selections stay on the Pi. Sign in online before field use. An open Digital session can still log if the network drops.

If ports are missing, run ls -l /dev/serial/by-id /dev/serial/by-path. arecord -l and aplay -l list capture and playback devices. For serial permission errors run sudo adduser "$USER" dialout and sign out and back in. For POTA/SOTA check the references on your contacts before export.
